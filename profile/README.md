### Fehler gefunden oder eine Idee?

Bitte eröffne nach Möglichkeit ein **Issue im passenden Repository**:

* Fehler in **Texten, Formeln, Abbildungen oder Musterlösungen** → [50ohm-contents-dl](https://github.com/DARC-e-V/50ohm-contents-dl/issues)
* Fehler oder Wünsche zur **Website und ihren Funktionen** → [50ohm](https://github.com/DARC-e-V/50ohm/issues)
* Fehler oder Wünsche zur **App** → [50ohm-pocket](https://github.com/DARC-e-V/50ohm-pocket/issues)
* Probleme mit **Deployment oder Serverkonfiguration** → [50ohm-ansible](https://github.com/DARC-e-V/50ohm-ansible/issues)

Alternativ erreichst du uns per E-Mail:

* **Fragenkatalog:** [fragenkatalog@darc.de](mailto:fragenkatalog@darc.de)
* **50ohm.de:** [50ohm@darc.de](mailto:50ohm@darc.de)
* **Apps:** [app@darc.de](mailto:app@darc.de)

### Mitmachen

Pull Requests sind jederzeit willkommen!

Wenn du regelmäßig an 50ohm.de mitarbeiten möchtest oder Fragen zur Mitarbeit hast, schau gerne in unserem **50ohm-Contributor-Kanal im DARC-Matrix** vorbei:

[**#50ohm-contribution:darc.de**](https://matrix.to/#/#50ohm-contribution:darc.de)

Du kannst uns außerdem unter [50ohm@darc.de](mailto:50ohm@darc.de) erreichen.
